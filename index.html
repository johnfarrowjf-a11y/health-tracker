Health Log 🩺
Your personal food, symptom and lifestyle tracker.
One-time setup needed — takes about 5 minutes.
Step 1 — Supabase database

Create a free database

Supabase stores your diary data securely in the cloud. Go to supabase.com, create a free account, then create a new project.

Once your project is ready, open the SQL Editor and run this query to create the data table:

create table health_logs ( id uuid default gen_random_uuid() primary key, date text unique not null, data jsonb not null, created_at timestamptz default now(), updated_at timestamptz default now() );

Then go to Project Settings → API to find your Project URL and anon/public key.

Step 2 — Anthropic API key

Get your API key

This powers the food photo analysis and weekly AI review. Go to console.anthropic.com, sign in, and create an API key under Account → API Keys.
