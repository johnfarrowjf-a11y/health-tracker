Health Log 🩺
Your personal food, symptom and lifestyle tracker.
One-time setup — takes about 5 minutes.
Step 1 — Supabase database

Create a free database

Go to supabase.com, create a free account and a new project. In the SQL Editor run this query:

create table health_logs ( id uuid default gen_random_uuid() primary key, date text unique not null, data jsonb not null, created_at timestamptz default now(), updated_at timestamptz default now() ); alter table health_logs enable row level security; create policy "Allow all" on health_logs for all using (true) with check (true);

Then go to Project Settings → API for your Project URL and anon/public key.

Step 2 — Anthropic API key

Get your API key

Go to console.anthropic.com → API Keys → Create Key. Copy the full key immediately — it's only shown once.
